# Download Policy

Download only legally available open-access PDFs.

Allowed:
1. arXiv PDF URLs for valid arXiv IDs.
2. OpenAlex OA PDF URLs from verified open-access locations.
3. Official publisher OA PDFs.
4. Institutional repository PDFs.
5. Public author homepage PDFs when non-paywalled.
6. User-provided legal PDF URLs.

Disallowed:
- Sci-Hub
- Library Genesis
- paywall bypass tools
- shared credential access
- browser-session downloads
- publisher PDFs available only through institutional subscription
- unauthorized scraping

For every attempted download, record:
- paper_id
- pdf_url
- source
- HTTP status
- content type
- file path
- checksum
- byte size
- retrieved_at
- success/failure reason

If no legal PDF URL exists, keep metadata and set download_status = unavailable.
